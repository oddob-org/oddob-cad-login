Oddob 中望 CAD 插件 —— 交付包 使用说明
================================================

一、环境要求
------------------------------------------------
- 中望 CAD 2025 / 2026 / 2027（64 位）
- .NET Framework 4.8 运行环境
- 本包只有一份，同时适用于中望 CAD 2025、2026、2027
  原因：中望自 2025 起启用新的二进制兼容系列，2026 / 2027 未改动 SDK；
  且 ZwManaged / ZwDatabaseMgd 无强名称，.NET 运行时按简单名绑定、不校验版本，
  所以用 2026 版 SDK 编译的产物可直接在 2025 / 2026 / 2027 中加载。

二、加载方式（二选一）
------------------------------------------------
方式 A：手动 NETLOAD（临时测试，重启 CAD 后失效）
  1. 打开中望 CAD。
  2. 命令行输入 NETLOAD 回车。
  3. 在文件对话框中选择本目录下的 Oddob.Zcad.dll。
  4. 加载成功后，命令行输入命令 OddobLogin 回车，即弹出登录窗口。

方式 B：自动加载（长期测试）
  1. 命令行输入 NETLOAD 加载一次 Oddob.Zcad.dll。
  2. 如需每次启动自动加载，可在 CAD 启动脚本（如 acad.lsp）中加入加载调用。

三、可用入口
------------------------------------------------
- 命令：OddobLogin
  作用：弹出登录窗口。
- LISP 函数：(Oddob_Login)
  作用：与 OddobLogin 等效，供 LISP 脚本调用。
- 登录结果会写入 LISP 符号：@oddpro-inte、@oddoption-inte、@oddent-inte、@oddentoption-inte（T / nil）。

四、网络配置
------------------------------------------------
- 配置文件 config.json 位于本目录下（与 Oddob.Service.dll 同级）。
- 内容：
    {
      "Host": "https://oddob.com",
      "Port": ""
    }
- 说明：
  * Host：后端服务地址，默认为 https://oddob.com。
  * Port：端口，留空表示使用默认端口（http 80 / https 443）。
  * 若删除 config.json，程序会使用内置默认值（即上面的地址），仍可正常使用。

五、重要注意事项
------------------------------------------------
1. 必须整个目录一起拷贝使用，不能只拷贝 Oddob.Zcad.dll！
   原因：Oddob.Service.dll、Panuon.WPF.UI.dll 等依赖以独立 DLL 形式随包发布，
   缺少同目录依赖 DLL 会加载失败。

2. 不要复制 ZwManaged.dll / ZwDatabaseMgd.dll。这两个程序集由中望 CAD 自身提供，
   本包已按 Private=false 处理，不会携带，避免与宿主版本冲突。

3. 本包为 Release 版本（DebugType=none，无 pdb）。如需排查异常，请构建 Debug 版本。

4. 用户设置与缓存写入 %LocalAppData%\Oddob\Settings 目录（首次运行自动创建）。

六、测试重点（建议）
------------------------------------------------
- 在中望 2025 / 2026 / 2027 上分别 NETLOAD，确认均能加载且 OddobLogin 弹出窗口。
- 登录窗口左侧静态图片是否正常显示。
- 图形验证码 / 手机验证码是否正常拉取。
- 登录、刷新 Token、获取用户信息流程是否通畅。
- 登录后 LISP 符号 @oddpro-inte 等是否被正确置为 T / nil。
